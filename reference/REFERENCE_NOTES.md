# 레퍼런스 이미지 설명

이미지 안의 글씨가 작으므로, 이미지와 함께 이 설명을 기준으로 해석한다.
노란 배경 영역 = 고객이 직접 구성한 테리웰 화면 시안, 흰 배경 영역 = 참고한 외부 사이트,
빨간 화살표/박스 = "이 부분을 참고해 달라"는 표시.

## 01_homepage-pages.jpg — 홈페이지 전체 구성
- **인트로 페이지(노란 영역 1)**: "헤더 ← 고정" 메모. 헤더 메뉴: 회사 소개 · 제품 소개 · 견적문의 · 공지사항, 우측 검색 아이콘.
  우측 아이콘 영역(빨간 박스)은 화면 하단 CUSTOM LAND 레퍼런스의 헤더 아이콘(검색·찜·장바구니·마이페이지 + 작은 텍스트 링크)을 참고하라는 표시.
  구성: 커튼 이미지 히어로 + "TERRYWELL / A Better Everyday, Woven into Every Towel." →
  둥근 모서리 카드 4개 → "Lollipop Stripe Towel" NEW 배너 → 푸터(로고, 042-0000-0000, 운영시간, 회사 정보).
- 인트로 카드에서 아래로 내려가는 화살표 → **커스텀 라벨 페이지**: 라벨 붙은 수건 이미지, "CUSTOM LABEL" 설명, [견적문의 바로가기] 버튼.
- **회사 소개 페이지(노란 영역 2)**: 왼쪽 레퍼런스(헬스케어 사이트의 텍스트+이미지 교차 구성) 참고.
  수건 이미지 + "Better Better Better" 타이포, 본문, 교차 이미지. 아래쪽 "DISCOVER MORE / HAVE A NICE AT HOME" 감성 섹션도 참고.
- **제품 소개 페이지(노란 영역 3)**: 탭 BEST · ALL · NEW · TOWEL, 검색, "Products" 3열 그리드,
  카드 예: Lollipop stripe towel / 롤리팝 스트라이프 타월. 왼쪽 가구 쇼핑몰(HIKONE 등) 그리드 참고.
- 기타 분위기 레퍼런스: re_, The Ordinary, SPACE (여백 많은 이미지 중심 레이아웃).

## 02_label-editor.jpg — "디자인 웹에서 편집 시 나오는 창"
- 인쇄 스티커 웹 에디터 레퍼런스. 원형 스티커 예시지만 테리웰은 **가로로 긴 직사각형 라벨**로 적용.
- 상단 어두운 바: 제품명, 실행취소, [?], 빨간 [편집종료].
- 캔버스 위: "재단 50×50mm / 작업 54×54mm / 1/1p". 선 3종(재단선·작업 사이즈·안전 영역).
- 왼쪽 큰 이미지 = **편집 가이드 모달**: 재단선/작업 사이즈/안전 영역 설명, "이미지와 PDF 파일 편집이 가능합니다!", 유의사항.
- 하단 툴바: 크기·페이지·사진·텍스트·디자인·스티커·배경 등. 누르면 바텀시트:
  사진=이미지 불러오기, 텍스트=제목/부제목/본문 추가, 디자인=템플릿 그리드+카테고리 드롭다운, 배경=커스텀 색상+팔레트.
  텍스트 선택 시 상단 툴바가 삭제·복제·정렬·글꼴·크기·색상 등으로 바뀜.
- 하트 키링 에디터 예시: "빨간색 선까지 반드시 이미지를 채워주세요", 줌 컨트롤, PNG 투명 배경 안내.
- 네임스티커 예시(빨간 박스): **"이름 선택하면 이름 변경 가능"** → 템플릿 속 텍스트를 탭해서 바로 수정.
- 고객 요청: 이 하단 툴바 목록 안에 **AI 항목을 추가** → 선택 시 이미지 생성 → 바로 편집.

## 03_product-detail.jpg — "제품 선택했을 때 나오는 창"
- **테리웰 시안(노란 영역 왼쪽)**: 수건 메인 이미지 + 색상별 썸네일, 제품명(Lollipop stripe towel / 롤리팝 스트라이프 타월),
  소재·중량·사이즈(수건 40×80cm / 라벨 4.5×6.5cm)·원산지, "* 수건 박스 별도 문의",
  색상 스와치(peach·soda·lemon·melon·berry), 수건과 라벨 위치 치수 도식.
  빨간 박스 "옆 레퍼런스 참조 → 디자인, 상품 가격 금액" 영역은 오른쪽 레퍼런스처럼 구성.
- **레퍼런스(키링 상품 페이지)**: 상품명·가격, 배송 안내 아코디언,
  디자인 [에디터로 편집]/[PDF 업로드] 토글("디자인 방식을 변경하면 기존 디자인은 초기화됩니다"),
  상품가격 박스([단가표], 수량 스테퍼, 공급가액, 부가가치세, 총 합계금액), 찜 하트 + [디자인하기] 버튼.
  ※ "속지 추가" 항목은 키링 전용이라 테리웰에는 넣지 않는다.
- "아래 스크롤 나오면 상세페이지": 탭(상품정보 · 유의사항 · 이용안내) + 상세 이미지.
- **PDF 업로드 시**: PDF·AI·EPS 업로드, 50MB 이하, 필수 동의 체크 2개, [제작가이드] [도안 파일] 버튼.
- 아래쪽 흰 영역 레퍼런스(T&L, DOMELLINI, ID Trim): 제품 상세 레이아웃·스펙 표·도식 표현 참고.
